# 🔬 Electronics Lab Assistant

Aplikasi web interaktif berbasis Python dan Streamlit yang dirancang sebagai asisten praktikum laboratorium Teknik Elektro.

## 🚀 Link Aplikasi Publik
- **Live App**: [https://electrolab-assistan-umjl36abgeqe7jjaczyrdp.streamlit.app](https://electrolab-assistan-umjl36abgeqe7jjaczyrdp.streamlit.app)
- **GitHub Repository**: [https://github.com/yusronahmadqodari/electrolab-assistan](https://github.com/yusronahmadqodari/electrolab-assistan)

## ⚡ Fitur Utama
1. **Kalkulator Hukum Ohm & Daya**: Menghitung $V$, $I$, $R$, dan $P$ dilengkapi penjelasan rumus otomatis.
2. **Resistor Seri & Paralel**: Menghitung nilai hambatan pengganti untuk rangkaian seri dan paralel.
3. **Konverter Satuan Elektro**: Konversi cepat untuk Volt (V, mV, kV), Arus (A, mA, µA), dan Hambatan (Ω, kΩ, MΩ).
4. **Catatan Hasil Praktikum**: Memungkinkan pengguna membuat ringkasan hasil pengamatan dan mengunduhnya sebagai file dokumen.
5. **Riwayat Perhitungan**: Menyimpan data kalkulasi sebelumnya secara dinamis.
