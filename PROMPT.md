# Master Prompt - Electronics Lab Assistant

## User Intent
Mengembangkan aplikasi web berbasis Python dan Streamlit bernama **Electronics Lab Assistant** untuk membantu mahasiswa teknik elektro dalam melakukan perhitungan praktikum di laboratorium.

## System Prompt & Functional Requirements
Aplikasi harus memiliki fitur-fitur utama berikut:
1. **Kalkulator Hukum Ohm & Daya Listrik**: Menghitung Tegangan (V), Arus (I), Hambatan (R), dan Daya (P) beserta rumus dan penjelasannya.
2. **Kalkulator Resistor Seri & Paralel**: Menghitung hambatan pengganti total dari beberapa resistor yang diinputkan.
3. **Konversi Satuan**: Konversi antar satuan elektro (Volt, Milivolt, Ampere, Miliampere, Ohm, Kiloohm).
4. **Catatan Praktikum**: Tempat menyimpan ringkasan hasil percobaan laboratorium dan opsi unduh file `.txt`.
5. **Riwayat Perhitungan**: Menyimpan riwayat kalkulasi yang telah dilakukan pengguna menggunakan Streamlit Session State.
